## byteinn.net 能帮你做什么

- **国内直接用**：不用海外手机号、不用外币信用卡，网站注册、在线充值，按实际用量计费。新用户注册即送体验额度。
- **一个 Key 调多家模型**：Claude、GPT、Grok 等主流模型都在一个账号里，新模型上架会第一时间在官网公告。
- **Claude Code、Codex 直接接入**：填上地址和 Key 就能用，不用自己折腾代理。
- **常用工具一键导入**：控制台里可以把 Key 一键导入 Cherry Studio、CC Switch、DeepChat、Lobe Chat 等客户端。
- **多条线路可选**：默认线路之外还有优选线路和负载均衡线路，哪条顺手用哪条。
- **每日签到**：登录后每天签到领额度。

## 三步开始

1. 打开 [byteinn.net](https://byteinn.net/register) 注册账号。
2. 在控制台创建一个 API Key。
3. 把地址和 Key 填进你常用的工具；或者下载 [ByteInn 客户端](https://github.com/byteinn-dev/byteinn-client)，登录就能开聊。

## 线路地址

| 线路 | 地址 |
|---|---|
| 默认线路（稳定低延迟，支持生图） | `https://byteinn.net` |
| 优选线路 | `https://byteinn.cc` |

## 不想配置？用专属客户端

[ByteInn 客户端](https://github.com/byteinn-dev/byteinn-client) 支持 Windows 与 macOS，内置 Claude Code 和 Codex 两个官方内核，登录 byteinn.net 账号就能用：多个对话并行、改动看得清能撤回、助理帮你拆任务，手机和聊天软件也能远程派活。
